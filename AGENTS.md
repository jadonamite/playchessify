# UI & Codebase Style Guidelines

## Strict No-Emojis Policy
- **NO emojis in the build or codebase**: Do NOT use emojis anywhere in UI text, labels, buttons, badges, modals, status indicators, or console logs.
- Use clean inline SVG icons, subtle chess piece glyphs (e.g. ♟, ♞, ♝, ♜, ♛, ♚), or typographic text styling instead.
